Shared style specification used for all icons:

> Use case: stylized-concept. Asset type: Roblox game UI icon. Bright polished
> 3D-cartoon simulator rendering, chunky proportions, thick dark navy outline,
> subtle highlights and soft internal shading. One centered original object with
> generous even padding and a strong readable silhouette at 48-64 pixels.
> Genuinely transparent background with preserved alpha. No words, letters,
> numbers, emoji appearance, frame, canvas border, logo, brand, or watermark.
