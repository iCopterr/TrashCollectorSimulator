ROBLOX UPLOAD

1. Upload each PNG through Creator Dashboard as an image/decal.
2. Wait for Roblox moderation if an image is initially unavailable.
3. Send Codex the resulting asset IDs with their filenames.
4. Codex will connect them to the redesigned responsive UI.

Recommended usage:
  Image = "rbxassetid://ASSET_ID"
  BackgroundTransparency = 1
  ScaleType = Enum.ScaleType.Fit

Keep all labels and numbers as Roblox TextLabels. Do not bake text into images.
