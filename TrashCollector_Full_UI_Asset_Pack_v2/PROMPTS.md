## Shared icon direction

> Use case: stylized-concept. Asset type: Roblox simulator game UI icon. Input images: the three supplied screenshots are style references only. Style/medium: polished chunky 3D cartoon sticker icon, saturated colors, beveled plastic surfaces, crisp highlights, thick dark navy outline and subtle drop shadow matching the reference simulator UI. ## Stud texture

Use repeating small L-shaped and square recessed studs like the reference panels and PLAY button. Keep it neutral medium gray so Roblox ImageColor3 can recolor it. Use soft top-left bevel highlights, subtle lower-right shadows, low contrast, orthographic framing, uniform edge-to-edge coverage, and no text, icons, borders, or full-canvas gradient.
